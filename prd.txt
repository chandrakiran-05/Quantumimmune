Project Name

QuantumImmune Dx — Quantum-Inspired ML System for Early Multi-Autoimmune Disease Detection

1. Problem Statement

Autoimmune diseases (80+ known types) are notoriously hard to diagnose early because symptoms overlap across conditions and lab markers are non-specific in early stages. Misdiagnosis/delay averages 4-7 years across common autoimmune diseases. Classical ML models struggle with high-dimensional, overlapping, imbalanced biomarker data. This project explores whether quantum-kernel-based ML (simulated via parallelized classical computation) can improve early multi-disease classification.

2. Objective

Build a prototype that takes patient lab/clinical inputs and predicts the likelihood and type of autoimmune disease (across 10-15 categories) at an early stage, using a Quantum Support Vector Machine (QSVM) pipeline, benchmarked against classical ML baselines.

3. Scope
In Scope
Multi-class classification across 10-15 autoimmune disease types
Quantum kernel feature mapping (simulated) for early-stage detection
Parallelized quantum circuit/kernel computation on classical CPU
Comparison dashboard: Classical ML vs Quantum-Kernel ML
Web-based demo interface (form input → prediction output)
Out of Scope (for hackathon prototype)
Real quantum hardware execution
Imaging-based diagnosis (MRI, ultrasound, radiographs)
Genomic/proteomic sequencing data
Clinical deployment / regulatory compliance (not a medical device)
Real-time EHR integration

2. Executive Summary

QuantumImmune Dx is a prototype diagnostic-support tool that classifies patient lab/clinical data into one of 10-15 autoimmune disease categories (or "healthy/non-autoimmune") using a Quantum Support Vector Machine (QSVM). Quantum circuits are simulated classically (no real QPU access), with kernel computation accelerated via multi-core parallel processing. The system is benchmarked against classical ML baselines (Random Forest, classical SVM) to demonstrate where quantum-kernel methods add value.

3. Problem Statement
3.1 Background

Autoimmune diseases affect ~5-8% of the global population across 80+ distinct conditions. Diagnosis is delayed an average of 4-7 years due to:

Overlapping, non-specific biomarkers (e.g., elevated CRP/ESR appears in dozens of conditions)
Symptom similarity across diseases in early stages
Reliance on specialist referral chains before definitive testing
3.2 Why Existing Classical ML Falls Short (for this specific problem)
High feature correlation and class overlap in biomarker space reduces separability with standard kernels (linear, RBF)
Small, imbalanced datasets per rare disease type limit deep learning approaches
Multi-way marker interactions (e.g., "ANA+ AND low complement AND age<40") are harder to capture with low-order classical kernels
3.3 Hypothesis Being Tested

Quantum feature maps, which embed data into an exponentially large Hilbert space via entangling circuits, can capture higher-order multi-marker interactions more efficiently than classical kernels — potentially improving separability in overlapping-biomarker, multi-class autoimmune classification, even under simulation.

FR4.1: Compute quantum kernel (state fidelity) between all pairs of training samples

FR4.4: Log computation time for sequential vs parallel runs (for benchmark reporting)
FR5: Model Training

12. ML Pipeline Detail
12.1 Training Phase
Load dataset → split train/val/test (stratified)
Preprocess (normalize, encode)
Build quantum feature map circuit (fixed structure, e.g., angle encoding + linear entanglement, depth=2)
Compute training kernel matrix K_train (N_train × N_train) — parallelized across patient pairs
Train SVC(kernel='precomputed') on K_train with one-vs-rest for 13 classes
Train classical RF and classical SVM baselines on same train split
Evaluate all models on validation set → tune hyperparameters (C, gamma for classical; circuit depth for quantum)
Final evaluation on held-out test set
12.2 Inference Phase
New patient input → preprocess (same pipeline as training)
Encode into quantum circuit → get state
Compute kernel between new patient and all (or top-k) support vectors — parallelized
Feed kernel vector into trained SVM decision function
Return class probabilities (via probability=True in sklearn SVC, calibrated with Platt scaling)
Display prediction + confidence
